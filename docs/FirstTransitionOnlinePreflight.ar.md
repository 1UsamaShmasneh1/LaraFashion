## 3. طريقة النسخ واختبارها وحدودها

أداة النسخ التابعة للنشر تفترض مصدرًا ثابتًا وتتحقق من stamp وحفظ الأعمال؛ لم تُستخدم على الإنتاج ولم يُستدعَ deploy-production.sh.

استُعملت أداة تشخيص مستقلة وفق [عقد Python 3.10](https://docs.python.org/3.10/library/sqlite3.html) و[SQLite Online Backup API](https://www.sqlite.org/c3ref/backup_finish.html):

- اتصال المصدر mode=ro وquery_only=ON، دون immutable/nolock أو DbContext أو startup.
- هدف جزئي جديد باستخدام O_EXCL، مع رفض المصدر/الوجهة المتطابقين والمسارات القائمة والروابط.
- دفعات 16 صفحة، وفاصل 2ms بين خطوات ناجحة، وsleep 50ms عند BUSY.
- حد كلي 90 ثانية، callback يوقف عند المهلة/5 BUSY متتالية/5 ثوان دون تقدم/حمل مرتفع أو تغير هوية المصدر، وwatchdog ينهي عملية النسخ نفسها إذا لم تعد callback.
- غلاف timeout للعملية الخاصة كلها 180 ثانية و3 ثوان للإلغاء النهائي؛ لا يستهدف خدمة المتجر.

- لا BEGIN IMMEDIATE/EXCLUSIVE، لا checkpoint/VACUUM/journal_mode على المصدر، ولا نسخ DB الحية أو WAL/SHM بـcp/scp.

## 9. خطة إعدادات وDP غير مفعلة

في الجذر الخاص: runtime.env.example وproposed-unit-deploy.diff.txt وConfigurationAndTransitionPlan.ar.md. كلها placeholders/NotForDeployment ولم تُثبت على الخادم.

النموذج يحفظ Production وloopback URLs وLARAFASHION_DATABASE_PATH الفعلي وuploads وإعدادات JWT الأربعة الحالية دون استخراج قيمها. يقترح لاحقًا EnvironmentFile خارج الويب والإصدار، مرجعًا في drop-in يحافظ على ExecStart وWorkingDirectory ومستخدم الخدمة، وإضافتي LARAFASHION_SERVICE_ENV_FILE وLARAFASHION_DATA_PROTECTION_PATH إلى deploy.env.

اقتراح ملفات جديدة في مهمة لاحقة: مجلد root:ubuntu 0750 وEnvironmentFile root:ubuntu 0640، دون كتابة للمجموعة/الآخرين؛ أداة التحقق الحالية التي تعمل كـubuntu تحتاج قراءته. ملف root:root 0600 قد يمنع تلك الأداة. لا اقتراح لتعديل صلاحيات القائم أثناء هذه المهمة.

يشترط أي تجهيز مستقبلي تحقق الملكية والروابط وفصل المسارات ومطابقة مرجع الخدمة والأداة وحفظ القيم الحالية على الخادم دون عرضها. لا JWT أو مفاتيح اصطناعية أو placeholders في إعداد حقيقي.

اختبار DP استعمل UID/GID 1001 وHOME=/home/ubuntu وcontent root=/var/www/larafashion/publish/ ومسارًا اصطناعيًا ثابتًا. قرأ المرشح token القديم والعكس في البيئتين. هذا لا يثبت استعمال العملية الحية لمسار HOME المرشح أو discriminator نفسه: **DataProtectionContinuity للإنتاج UNKNOWN**. لا key ring حقيقي منقول أو مفاتيح بديلة أو instrumentation/restart على الخادم.

## 10. ما يمنع الانتقال النهائي وحماية الأعمال الأحدث

ما زال EnvironmentFile الحقيقي غير مجهز وDP الفعلي غير مثبت وmanifest تعافٍ سابق مقبول غائبًا، وعقد health السابق غير متوافق. تحقق جميع الكتّاب وبوابات GitHub وإصدار مرشح نظيف ذي مصدر مثبت يحتاج مرحلة لاحقة. لا LARAFASHION_PRODUCTION_ACCEPTED أو متغيرات/أسرار Actions تغيرت.

مسار النشر الحالي يوقف الكتّاب. شرط المستخدم «لا أريد إيقاف خدمة المتجر أو ضياع البيانات» يمنع تنفيذه؛ نجاح الدراسة لا يرفع هذا المنع. يلزم قرار منفصل حول انتقال مصرح به يتضمن توقفًا، أو دراسة توافق وتصميم مستقل بإثباتات جديدة. لا نشر متوازٍ حي أو ترحيل مباشر أثناء استقبال الطلبات أو إضعاف حراس التعافي لتجاوز الشرط.

مثال: طلب يصل بعد 16:00:51.817550 يبقى في الإنتاج وقد لا يظهر في هذه اللقطة. غيابه محليًا ليس فقدًا ولا يجيز استبدال الإنتاج. ممنوع رفع النسخة المترقية أو مزامنة جداولها أو استخدامها لاحقًا لإثبات الإنتاج دون إعادة تقييم أعماله الحديثة.

هذه ليست حزمة تعافٍ كاملة؛ الصور والإعدادات والمفاتيح الحقيقية غير مجموعة. فشل محلي لا يطلق rollback أو restart بعيدًا.
